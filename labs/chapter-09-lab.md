# Chapter 9 Lab: Domain 10: Application Security

**Estimated time:** 18 minutes

## Exercise

Review a sample CI/CD pipeline configuration for hardcoded secrets, insert a secrets-manager reference in place of the hardcoded credential, and map where SAST/DAST stages should be added in the pipeline

## Key takeaway

Application security in the cloud depends on embedding security testing and secrets management directly into the CI/CD pipeline, not bolting it on afterward.
