# Chapter 8 Lab: Domain 9: Data Security

**Estimated time:** 18 minutes

## Exercise

Classify a sample dataset into sensitivity tiers, select the appropriate encryption and key management model (provider-managed, BYOK, or HYOK) for each tier, and document the lifecycle controls needed at each stage

## Key takeaway

Data security controls - encryption, key management, tokenization, and DLP - must be applied according to data classification and lifecycle stage, not uniformly.
