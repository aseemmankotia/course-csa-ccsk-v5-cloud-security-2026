# Chapter 6 Lab: Domain 7: Infrastructure and Networking

**Estimated time:** 18 minutes

## Exercise

Design a network segmentation diagram for a three-tier application using security zones, then convert it into a micro-segmentation policy that enforces workload-to-workload rules instead of zone-to-zone rules

## Key takeaway

Cloud network security requires moving beyond perimeter zones to workload-level micro-segmentation enforced through software-defined controls.
