# Chapter 10 Lab: Domain 11: Incident Response and Resilience

**Estimated time:** 18 minutes

## Exercise

Draft a cloud incident response runbook covering detection, containment (e.g., isolating a compromised resource), evidence preservation steps, and recovery, explicitly noting which steps require provider cooperation

## Key takeaway

Effective cloud incident response requires pre-planning around shared responsibility, evidence volatility, and clearly defined RTO/RPO-driven resilience strategies.
