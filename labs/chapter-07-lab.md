# Chapter 7 Lab: Domain 8: Cloud Workload Security

**Estimated time:** 20 minutes

## Exercise

Perform a workload security review checklist: scan a sample container image manifest for known-bad base images, review a Kubernetes pod security policy, and scope a serverless function's execution role to least privilege

## Key takeaway

Workload security requires layered controls - image scanning, runtime protection, orchestration-level policy, and least-privilege execution roles - tailored to each compute model.
