# Chapter 3 Lab: Domain 3: Risk, Audit, and Compliance

**Estimated time:** 18 minutes

## Exercise

Map three regulatory obligations (e.g., data residency, breach notification, encryption at rest) to relevant CCM control domains using an excerpt of a CAIQ questionnaire

## Key takeaway

The CCM defines the controls, CAIQ documents a provider's implementation of them, and compliance inheritance lets customers build on that evidence rather than re-auditing everything.
