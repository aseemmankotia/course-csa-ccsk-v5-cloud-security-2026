# Chapter 4 Lab: Domain 5: Identity and Access Management

**Estimated time:** 18 minutes

## Exercise

Design a federated IAM model for a company using an external IdP, mapping RBAC roles to least-privilege entitlements and identifying which accounts require just-in-time privileged access

## Key takeaway

Cloud IAM security depends on federated trust, least-privilege entitlements, and time-bound privileged access rather than standing permissions.
