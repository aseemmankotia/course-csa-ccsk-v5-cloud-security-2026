## Domain 9: Data Security — Cheat Sheet

### Data Security Lifecycle (6 phases)
| Phase | Focus | Typical Control |
|---|---|---|
| Create | Classification at origin | Labeling, DLP tagging |
| Store | Data at rest | Encryption, access control |
| Use | Active processing | Access control, in-memory protection |
| Share | Data leaving org boundary | Egress DLP, encryption in transit |
| Archive | Long-term retention | Encryption, retention policy |
| Destroy | End of life | Cryptographic erasure (multi-tenant), physical destruction (owned media) |

### Key Management Models
| Model | Key generated by | Key stored where | Provider access | Customer control |
|---|---|---|---|---|
| Provider-managed | Provider | Provider KMS | Full | Lowest |
| Customer-managed (CMK) | Customer | Provider HSM/KMS | Some (operational) | Medium |
| BYOK | Customer | Provider KMS (imported) | Some (operational) | Medium-High |
| HYOK | Customer | External to provider | None (external key manager invoked) | Highest |

### Tokenization vs Encryption
| | Tokenization | Encryption |
|---|---|---|
| Relationship to original | None (lookup only) | Mathematical (key-based) |
| Reversal requires | Token vault access | Correct key |
| Format preservation | Common (e.g., 16-digit) | Not typical |
| Compliance benefit | Reduces PCI DSS scope | Meets general at-rest/in-transit mandates |

### Data Classification (typical 4-tier)
| Label | Example | Control intensity |
|---|---|---|
| Public | Marketing material | Minimal |
| Internal | Internal memos | Basic access control |
| Confidential | Financial reports | Encryption + access control |
| Restricted | HR/health/PII/PCI data | Strongest encryption, DLP, strict IAM |

### DLP Types
- **Content-aware:** pattern/regex matching on actual data (SSN, PAN, keywords).
- **Context-aware:** inspects metadata — user, destination, channel, time of transfer.

### Encryption Baselines
- In transit: TLS 1.2+ (1.3 preferred); SSL and TLS 1.0/1.1 deprecated.
- At rest: AES-256 commonly referenced as strong default.

### Exam Gotchas
- BYOK ≠ HYOK: BYOK keys still touch provider infrastructure; HYOK keys never leave customer control.
- Tokenization is NOT encryption — no key, no reversible math, uses a vault mapping.
- Cryptographic erasure is the standard answer for Destroy phase in multi-tenant public cloud (no physical media access).
- DLP at Share phase ≠ DLP at Store phase — know which lifecycle stage a scenario describes.
