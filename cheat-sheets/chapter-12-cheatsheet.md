# Chapter 12 Cheat Sheet: Exam Simulation & Time Management

## Time Budget
| Metric | Value |
|---|---|
| Total exam time | 90 minutes |
| Total questions | 60 |
| Pace target | ~1.5 min/question |
| Passing score | 80% |
| Final review buffer | Reserve last 10–15 min |
| Max miss allowed | 12 questions and still pass |

## Triage Decision Rule
| Situation | Action |
|---|---|
| Know it in <1.5 min | Answer, move on |
| Unsure after 1.5–2 min | Best guess, flag, move on |
| Totally stuck at 3+ min | Guess, flag, move on immediately — do not exceed |
| Never | Leave blank — a guess beats zero credit |

## Open-Book Lookup Rules
- Use Ctrl+F/keyword search on CCM, CSA Security Guidance, ENISA docs — never read linearly during a timed question.
- Know document structure BEFORE the exam: CCM = 17 control domains (searchable by control ID); CSA Guidance = 14 narrative domains; ENISA = risk-assessment/top-risks focus.
- Only look up items you are genuinely uncertain about — lookups cost time.

## Commonly Confused Pairs (Review These Last 10 Minutes)
| Pair | Distinction |
|---|---|
| Governance vs. Management | Governance = policy/oversight/accountability; Management = operational execution |
| CCM vs. CAIQ | CCM = control framework; CAIQ = provider self-assessment questionnaire against CCM |
| RTO vs. RPO | RTO = max downtime to restore; RPO = max data loss window |
| STAR Level 1/2/3 | Level 1 = self-assessment (CAIQ); Level 2 = 3rd-party audit; Level 3 = continuous monitoring |

## Reading Scenario Questions
1. Read the LAST sentence first — it usually contains the qualifier (BEST, MOST, LEAST, FIRST).
2. Eliminate options that are technically true but don't match the qualifier.
3. Watch for distractors referencing deprecated frameworks or wrong domain scope.
4. If two options seem correct, the qualifier word decides which one wins.

## Final Review Window Protocol
1. Stop answering new questions once buffer time is reached.
2. Go only to flagged questions.
3. Sort mentally by confidence — lowest confidence reviewed first.
4. Only change an answer if you find concrete new reasoning — don't change out of anxiety alone.
