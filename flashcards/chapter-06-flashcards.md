## Chapter 6: Domain 7: Infrastructure and Networking — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Micro-segmentation vs traditional segmentation — key difference? | Traditional segmentation isolates at the network/subnet level (VLANs, perimeter firewalls); micro-segmentation enforces policy at the individual workload/host level, often via hypervisor or agent, limiting lateral movement even within the same subnet. Exam tip: micro-segmentation = workload-level enforcement. |
| 2 | Stateful vs stateless packet filtering — core difference? | A stateful firewall (e.g., security group) tracks connection state and auto-allows return traffic; a stateless firewall (e.g., NACL) requires explicit rules for both inbound AND outbound traffic. Exam tip: forgetting the outbound rule for stateless filtering is a classic trap. |
| 3 | What does SDN separate that traditional networking does not? | SDN decouples the control plane (routing/policy decisions) from the data plane (packet forwarding), enabling centralized, programmable, API-driven network management. Exam tip: compromising the SDN controller compromises the entire network's control plane — a high-value single point of failure. |
| 4 | Site-to-site VPN vs point-to-site VPN? | Site-to-site connects two networks continuously (e.g., on-prem to cloud VPC); point-to-site connects a single client device to a network. Exam tip: site-to-site = network-to-network, point-to-site = client-to-network. |
| 5 | Private/dedicated connectivity vs VPN over the internet? | Dedicated private connectivity uses a physical/logical link that bypasses the public internet, giving predictable performance and reduced exposure; VPN encrypts traffic but still traverses the public internet. Exam tip: choose private connectivity when consistent bandwidth/latency and reduced internet exposure matter most. |
| 6 | Security zone concept in cloud networking? | A logical grouping of resources sharing a trust level/security requirement (e.g., DMZ, app tier, data tier), separated from other zones by controlled connectivity points. Exam tip: security zones map trust boundaries to network segments/subnets. |
| 7 | IKE (used to establish IPsec VPN tunnels) uses which UDP port? | UDP 500 (and UDP 4500 for NAT traversal). Exam tip: IPsec is the standard protocol suite underlying most cloud site-to-site VPNs. |
| 8 | Security group scope vs Network ACL scope (typical cloud implementation)? | Security groups typically apply at the instance/interface level (stateful); NACLs typically apply at the subnet level (stateless). Exam tip: use both together — NACL for broad subnet-level policy, SG for granular per-instance policy. |
| 9 | Why is micro-segmentation critical for compliance-scoped workloads (e.g., PCI)? | It limits lateral movement between workloads even inside the same subnet/zone, ensuring a compromised system can't freely reach the in-scope environment. Exam tip: enforcement is identity/workload-based, not just IP-based. |
| 10 | SDN security implication: what new attack surface is introduced? | The centralized SDN controller/control plane — if compromised, an attacker can reprogram network flows across the entire environment. Exam tip: control-plane compromise is far worse than a single device compromise. |
| 11 | Default posture recommended for security groups/NACLs in cloud environments? | Default deny all inbound and outbound; explicitly allow only required ports/protocols/sources. Exam tip: least privilege applies to network rules just as it does to IAM. |
| 12 | End-to-end compute + network plane security — what must be layered together? | Host-based controls (agents, micro-segmentation), network controls (security groups/NACLs, security zones), and secure connectivity (VPN/private links) — defense in depth across all planes. Exam tip: no single control is sufficient; the exam tests the layered approach. |
